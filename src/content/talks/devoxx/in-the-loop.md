This year I let AI agents write most of my code and stopped reviewing it. It worked until production broke and I couldn't find my way around my own project. I had been running a dark software factory.

This talk is how I got back in the loop. I built Groma.md, an open-source tool that keeps a live C4 map of your architecture in Markdown, curated by your coding agent. On stage I scan a large Java repository from scratch, watch agents work Backlog.md tasks on the map, and review what they changed.
